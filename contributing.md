# Contribution Guidelines

Thank you for helping improve this list.

## Adding an item

- Search the list first so you don't suggest a duplicate.
- Add something you can personally recommend.
- Open a separate pull request for each item.
- Add the item at the bottom of the relevant category.
- Use this format: `- [Name](https://example.com) - Description.`
- Start the description with an uppercase letter and end it with a period.
- Keep the description short and objective. Don't use marketing language, badges, or affiliate links.
- Use the project's current official URL.
- Check spelling and grammar.
- Remove trailing whitespace.
- Give the pull request a useful title.

## Removing an item

Open a pull request that explains why the item should go. A broken official URL, an unmaintained project, or a duplicate are good reasons.

## Updating your pull request

If a maintainer asks for changes, edit the existing pull request. You don't need to open a new one. [This guide](https://github.com/RichardLitt/knowledge/blob/master/github/amending-a-commit-guide.md) explains how.
